Cryptódromo · Race

Glosario

Términos básicos para entender la mecánica que conecta datos de mercado y carreras virtuales.

Activo

Instrumento o token al que se asocia un corredor en la experiencia.

Fixture

Conjunto local de datos y participantes preparado para reproducir una o varias carreras.

Input

Dato de entrada que el motor de carrera utiliza para calcular el avance o la velocidad de un competidor.

Variación porcentual

Cambio de precio expresado como porcentaje entre dos momentos de referencia.

Dosis

Tramo o aplicación temporal de un input durante la carrera. La patente describe ejemplos de dosificación periódica.

Coeficiente

Parámetro que puede modular la aplicación de un dato. Su efecto exacto depende de las reglas de la implementación.

RNG

Sigla en inglés de generador de números aleatorios. La propuesta de Cryptódromo explora datos de mercado como motor de la competencia; cualquier componente aleatorio visual debe explicarse y distinguirse del criterio de resultado.

Una mecánica de carrera que convierte variaciones de precio en movimiento visual. Demo con datos de prueba; sin apuestas ni cotizaciones en vivo.
